# Technical Leadership

This domain focuses on growing beyond coding into technical leadership and
organization-level impact. It covers staff-plus IC leadership, engineering
management systems, evidence-based performance through delivery science, and
the judgment and measurement skills behind high-stakes decisions.

Concept IDs are subject-scoped (e.g. `staff-engineer/07`), so this `technical-leadership/` folder organizes files on disk without changing how you refer to a concept.

Path), the management path (An Elegant Puzzle, The Manager's Path), and cross-cutting
