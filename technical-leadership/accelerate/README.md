# Accelerate: The Science of Lean Software and DevOps

This subject translates delivery and operational performance into measurable,
evidence-based capabilities. You will learn the DORA metrics, the technical and
cultural drivers behind them, and how to avoid metric theater by focusing on
outcomes that correlate with real organizational performance.

**Source book:** *Accelerate: The Science of Lean Software and DevOps* - Nicole Forsgren, Jez Humble, Gene Kim (IT Revolution, 2018).

**Seniority baseline:** senior (lessons range senior->staff).

**How to use this subject:** read a lesson on your own, then ask to *discuss
`accelerate/<NN>`* (e.g. *"discuss `accelerate/03`"*). Ordered by dependency: evidence model and metrics first, then capability drivers, then transformation and governance implications.
