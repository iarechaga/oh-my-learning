# The Pragmatic Programmer

The philosophy layer of the software-engineering track: the mindset and everyday habits
that separate effective, adaptable developers from the rest - taking responsibility for
your craft, keeping code DRY and orthogonal, decoupling aggressively, and using tools
and tests deliberately. Broad and principle-driven; most later subjects (Clean Code,
Refactoring, Legacy Code) put these principles into concrete practice.

**Source book:** *The Pragmatic Programmer: Your Journey to Mastery* (20th Anniversary
edition) - David Thomas and Andrew Hunt (Addison-Wesley, 2019).

**How to use this subject:** read a lesson on your own, then ask to *discuss
`pragmatic-programmer/<NN>`* (e.g. *"discuss `pragmatic-programmer/03`"*). Ordered
roughly by theme: philosophy first, then the core pragmatic techniques, then design,
delivery, and pragmatic projects.

**Seniority baseline:** mid (lessons range junior->senior).
