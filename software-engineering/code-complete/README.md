# Code Complete

The construction layer of the software-engineering track: craftsmanship in the small -
how to write individual variables, routines, and classes well, program defensively, and
manage the complexity that accumulates line by line. Where Clean Architecture works at
the module/system level, Code Complete is about the code you type every day. Pairs
naturally with Clean Code.

**Source book:** *Code Complete: A Practical Handbook of Software Construction* (2nd
edition) - Steve McConnell (Microsoft Press, 2004).

**How to use this subject:** read a lesson on your own, then ask to *discuss
`code-complete/<NN>`* (e.g. *"discuss `code-complete/05`"*). Ordered by dependency:
foundational metaphors and design first, then variables and routines, then defensive
construction and quality.

**Seniority baseline:** mid (lessons range junior->senior).
