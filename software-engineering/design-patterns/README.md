# Design Patterns

The design-vocabulary layer of the software-engineering track: the original 23
object-oriented patterns from the "Gang of Four", grouped as **creational**,
**structural**, and **behavioral**. Each pattern names a recurring design problem and a
proven solution, giving you a shared vocabulary ("use a Strategy here", "that's a
Decorator") and a toolkit of flexible, reusable designs. It underpins later pattern
catalogs (Enterprise Patterns, Microservices Patterns).

**Source book:** *Design Patterns: Elements of Reusable Object-Oriented Software* - Erich
Gamma, Richard Helm, Ralph Johnson, and John Vlissides (Addison-Wesley, 1994).

**How to use this subject:** read a lesson on your own, then ask to *discuss
`design-patterns/<NN>`* (e.g. *"discuss `design-patterns/04`"*). Ordered by dependency:
foundational principles first, then creational, structural, and behavioral patterns
(grouped so related patterns are learned together).

**Seniority baseline:** mid (lessons range junior->senior).
