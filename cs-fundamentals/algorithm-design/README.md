# Algorithm Design (Kleinberg and Tardos)

This subject focuses on the core algorithm design toolkit: how to recognize problem
structure, choose the right strategy, and justify correctness with clean proof patterns.
It emphasizes thinking in paradigms - greedy, divide and conquer, dynamic programming,
network flow, and NP-completeness.

**Source book:** *Algorithm Design* - Jon Kleinberg and Eva Tardos (Pearson, 2005).

**Seniority baseline:** mid-senior (lessons range mid->senior).

**How to use this subject:** read a lesson on your own, then ask to *discuss
`algorithm-design/<NN>`* (e.g. *"discuss `algorithm-design/03`"*). Ordered by dependency: design and proof foundations first, then major paradigms, then complexity boundaries and approximation.
