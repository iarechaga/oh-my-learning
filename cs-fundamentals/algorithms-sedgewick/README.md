# Algorithms (Sedgewick and Wayne)

This subject takes a practical, implementation-first path through classic algorithms
and data structures, with emphasis on choosing concrete representations and understanding
real performance behavior. It is ideal for turning theory into code-level intuition.

**Source book:** *Algorithms* - Robert Sedgewick and Kevin Wayne (Addison-Wesley, 2011).

**Seniority baseline:** mid (lessons range junior->senior).

**How to use this subject:** read a lesson on your own, then ask to *discuss
`algorithms-sedgewick/<NN>`* (e.g. *"discuss `algorithms-sedgewick/03`"*). Ordered by dependency: implementation basics and analysis first, then sorting/searching, then graph and string algorithms.
