# Domain-Driven Design Distilled

This subject is the short DDD primer: a compact pass through strategic and tactical
design so you can build a correct mental map quickly before going deeper in other DDD
books. It emphasizes the essential vocabulary, key boundaries, and practical modeling
habits without the full implementation detail of larger texts.

**Source book:** *Domain-Driven Design Distilled* - Vaughn Vernon (Addison-Wesley, 2016).

**Seniority baseline:** mid (lessons range junior->senior).

**How to use this subject:** read a lesson on your own, then ask to *discuss
`ddd-distilled/<NN>`* (e.g. *"discuss `ddd-distilled/03`"*). Ordered by dependency: quick strategic framing first, then tactical essentials, then lightweight implementation and adoption guidance.
