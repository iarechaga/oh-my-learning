# Learning Domain-Driven Design

This subject is the modern on-ramp to DDD: it starts from business context and
strategic design, then connects those decisions to tactical modeling and architecture.
It is written for current delivery environments, so it helps you move from abstract DDD
ideas to practical design choices in teams shipping software continuously.

**Source book:** *Learning Domain-Driven Design* - Vlad Khononov (O'Reilly, 2021).

**Seniority baseline:** senior (lessons range mid->staff).

**How to use this subject:** read a lesson on your own, then ask to *discuss
`learning-ddd/<NN>`* (e.g. *"discuss `learning-ddd/03`"*). Ordered by dependency: strategic framing and problem-space analysis first, then tactical modeling, then architecture and implementation patterns.
