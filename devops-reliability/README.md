# DevOps, Cloud & Reliability

This domain covers how software is operated in production once it leaves the laptop.
It connects delivery flow, fast feedback, and reliability engineering into one
operating model: ship value quickly, detect problems early, and keep user-facing
systems dependable under real-world change and failure.

Concept IDs are subject-scoped (e.g. `sre/07`), so this `devops-reliability/` folder organizes files on disk without changing how you refer to a concept.
