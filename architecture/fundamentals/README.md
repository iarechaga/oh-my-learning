# Fundamentals of Software Architecture

The consolidation layer of the architecture track: the vocabulary, characteristics,
styles, governance practices, decision records, risk techniques, communication habits,
and leadership skills that turn a strong developer into a software architect.

**Source book:** *Fundamentals of Software Architecture: An Engineering Approach* -
Mark Richards and Neal Ford (O'Reilly, 2nd ed., 2025).

**How to use this subject:** read a lesson on your own, then ask to *discuss
`fundamentals/<NN>`* (e.g. *"discuss `fundamentals/09`"*). Ordered by dependency:
architectural thinking and characteristics first, then modularity and styles, then
decision-making, risk, communication, and leadership.

**Seniority baseline:** senior (lessons range mid->staff).
