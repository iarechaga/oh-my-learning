# System Design Interview

The interview-practice layer of the track: a repeatable framework for tackling
open-ended "design X" problems under time pressure, plus a set of worked end-to-end
designs. It reuses the same building blocks as the System Design subject (load
balancing, caching, sharding, queues) but organizes them around a step-by-step
interview method and complete case studies. Cross-links to System Design and DDIA.

**Source book:** *System Design Interview - An Insider's Guide* - Alex Xu (Volume 1;
ByteByteGo / independently published, 2020).

**How to use this subject:** read a lesson on your own, then ask to *discuss
`system-design-interview/<NN>`* (e.g. *"discuss `system-design-interview/03`"*). Ordered
by dependency: the framework and back-of-the-envelope skills first, then progressively
harder case studies.

**Seniority baseline:** mid-senior (lessons range junior->senior).
