# Designing Data-Intensive Applications (DDIA)

The theoretical foundation of the learning track: how data systems actually work
under the hood — reliability, data models, storage, replication, partitioning,
transactions, consistency/consensus, and batch/stream processing.

**Source book:** *Designing Data-Intensive Applications* — Martin Kleppmann (O'Reilly).

**How to use this subject:** read a lesson on your own, then ask to *discuss
`ddia/<NN>`* (e.g. *"discuss `ddia/07`"*). Concepts are ordered by dependency, so
top-to-bottom is a sensible reading order. After each discussion, the row below is
updated with your mastery rating and a link to the session record.
